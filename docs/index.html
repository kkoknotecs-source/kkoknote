앱 설치 방법 (갤럭시)

콕노트는 정부 창업지원사업 ‘모두의 창업’ 1라운드에 선정된 프로젝트로, 개발자가 직접 만들고 운영하는 테스트 앱이에요. 설치할 때 뜨는 경고는 아직 구글플레이에 정식 등록되기 전이라 나오는 안내예요. 아래처럼 무시하고 설치를 눌러 주세요. 궁금한 점은 kkoknote.cs@gmail.com으로 언제든 물어봐 주세요.

  1. 1. 파일 받기‘파일 다운로드’ 창에서 다운로드를 누르고, 받은 파일을 열어요. ‘권한 필요’가 뜨면 설정에서 권한 허용을 켜 주세요.
  2. 2. 경고 창 넘기기‘앱 설치가 권장되지 않음’이 뜨면 무시하고 설치를 눌러요.
  3. 3. 확인 말고 세부정보 더보기‘기기 보호를 위해 앱 차단됨’이 뜨면 파란 확인은 누르지 말고, 세부정보 더보기를 눌러요.
  4. 4. 무시하고 설치하기아래에 나온 무시하고 설치하기를 눌러요.
  5. 5. 설치 완료열기를 누르면 콕노트가 시작돼요.
